# Kopano

Lesotho's social discovery platform: meet people, make friends, discover places and events.

## Apps
- `apps/mobile`: Flutter application targeting Android, iOS, and web.

## Getting started
Install Flutter SDK 3.24 or newer, then:

```sh
cd apps/mobile
flutter pub get
flutter run -d chrome
```

The initial release is a UI-only prototype using demonstration content. No real matching, messaging, payments, reservations, or profile verification are active.

## Brand
Purple `#5E0BA6`, pink `#E83E8C`, dark ink `#220A35`, white `#FFFFFF`.

## Safety
Production requires 18+ eligibility checks, blocking, reporting, moderation, privacy controls and verified backend authorization before public release.
